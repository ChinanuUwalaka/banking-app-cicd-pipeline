# Banking Application CI/CD Pipeline

## Overview

This project demonstrates an automated CI/CD pipeline for a sample banking application using Jenkins, Docker, GitHub, and Linux.

## Technologies Used

- Jenkins
- Docker
- GitHub
- Linux

## Pipeline Stages

1. Source Code Retrieval
2. Build
3. Testing
4. Docker Image Creation
5. Deployment

## Skills Demonstrated

- Continuous Integration
- Continuous Delivery
- Containerization
- Automation
